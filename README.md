# mariadopheide.com

Статический одностраничный сайт. Сборка не требуется — Netlify публикует
содержимое репозитория как есть.

## Структура

```
index.html              разметка страницы
assets/
  css/styles.css        все стили
  js/main.js            плавная прокрутка + карусель отзывов
  images/               изображения
netlify.toml            конфигурация деплоя
```

## Где что править

| Задача | Файл |
|---|---|
| Тексты, секции, ссылки | `index.html` |
| Цвета, шрифты, отступы | `assets/css/styles.css` |
| Адаптив под телефоны | `assets/css/styles.css`, блок `@media (max-width:900px)` |
| Поведение карусели | `assets/js/main.js` |

Палитра и тени заданы переменными в начале `styles.css` (`:root`).

## Локальный просмотр

```bash
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765 — важно смотреть именно через сервер,
а не открывать `index.html` двойным кликом: по `file://` относительные
пути к CSS и картинкам не работают.

## Публикация

```bash
git add -A && git commit -m "описание правки" && git push
```

Netlify пересобирает сайт автоматически после каждого push в `main`.

## Ссылка на запись

Ссылка на календарь встречается в `index.html` шесть раз. При смене
календаря заменить все вхождения:

```bash
grep -n "calendar.app.google" index.html
```
